# My-own-machine-learning
2026,the assignment of my curriculum&lt;Machine Learning>

This project takes the 10-class classification of Fashion-MNIST apparel images as its core task. It integrates three major technical branches: traditional machine learning, fundamental deep learning and unsupervised feature learning, and establishes a comparative experimental system for multiple algorithms. Based on the Python ecosystem, the team adopted the scikit-learn and TensorFlow-Keras frameworks to implement five classic models, namely Softmax Logistic Regression, Random Forest, Fully Connected Neural Network, Convolutional Neural Network (CNN) and Autoencoder. The entire experimental workflow was completed, including dataset loading, data preprocessing, model construction, training and parameter tuning, metric evaluation, and visual analysis.

The experiments focus on the classification, feature extraction, dimensionality reduction and reconstruction, as well as clustering visualization of high-dimensional pixel image data. The performance of different algorithms is compared in terms of classification accuracy, training efficiency, model stability, generalization ability and hardware compatibility. Meanwhile, targeted debugging and optimization were carried out to address practical engineering issues such as model overfitting, non-convergent iteration, redundant high-dimensional features and misclassification of similar samples. Finally, the advantages, disadvantages and applicable scenarios of each algorithm are summarized, providing experimental evidence and selection references for practical engineering applications including lightweight image classification, embedded vision deployment and unsupervised feature engineering.
